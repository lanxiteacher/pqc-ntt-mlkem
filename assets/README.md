**主责：C**（维护者）｜ 状态：⬜ 未开工

全组的截图、录屏、波形图，统一命名、统一目录。
**素材来源是 A、B**，你是收口的人。

---

## 命名约定

```
assets/YYYY-MM-DD_<谁>_<一句话>.<后缀>
```

例：

```
2026-09-22_A_折叠度三档Vivado实测对比表.png
2026-09-23_B_16组向量逐比特对拍全绿.png
2026-09-25_A_上板串口第一次收到数据.mp4
2026-09-28_C_NTT第一层蝶形动画.gif
```

### 细则

| 字段 | 规则 |
|---|---|
| `YYYY-MM-DD` | **素材产生那天**，不是补录那天。补录会毁掉时间线 |
| `<谁>` | `A` / `B` / `C`，**单个大写字母** |
| `<一句话>` | 中文，说清**「这张图证明了什么」**。不许写 `截图1` `未命名` `新建文件` |
| 后缀 | `.png` 静态图（截图 / 波形图 / Vivado 报告截图）<br>`.mp4` 录屏<br>`.gif` 30 秒以内的短动效（能直接插进报告的那种） |
| 合法字符 | ⚠️ Windows 不允许 `/ \ : * ? " < > \|`，一句话里**一个都不能有** |

## 规矩

**1. 每完成一小步就丢进来，别攒。**
「对拍通过」那张截图是报告和视频里最有说服力的素材，而它只在那 10 分钟里存在过。
A、B 忙起来最容易忘 —— **忘了 C 就去要**。

**2. 存原始文件，不要只存进 PPT/Word。**
剪视频时要从原始文件取，从 PPT 里抠出来的图是糊的。

**3. 一个素材至少被用三次。**
报告配图、演示视频、答辩 PPT 都从这里出 —— 所以命名要让人**六个月后还找得到**。

**4. 报告里用到的图不要在这里删。**
`../report/figures/` 里的是"报告用的那一版"（可能裁过、加过标注），
这里是原始件。两边都留着。
