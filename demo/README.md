## 数值口径与自检

- **口径**：每层都做 `canonical mod q` 归一化，落回 **0..3328**
  （与 `../refsim/ntt_ref_tool.c` 的输出口径一致：`poly_ntt` 后 `to_canon` 再打印）
- **自检判据（硬）**：第 7 层必须**逐值等于** `../research/mlkem_kat/ntt_out.hex`。
  脚本不通过就非零退出、不写产物。
- **当前结果**：**16/16 组全部逐值一致**（4096 个系数）
- **非退化检查**：输入 4096 个系数里 **2355 个不同值** —— 与项目记录里记的同一个数字，
  说明这 16 组向量没有退化，且这套实现与 C 参考实现逐比特等价
- 页面上的蝶形算式也**独立复算过**：按页面写的公式
  （`t = zeta × b`；`a′ = a + t`；`b′ = a − t`）重算全部 16 组 × 7 层，
  **28672 个输出值 0 处不符**

> 生成器里对 `int16` 的截断是**显式**做的（`i16()`），乘法用 `Math.imul` 保证 32 位不溢出 ——
> 否则与 C 的 `int16_t` 语义不一致，第 7 层就对不上。改这个脚本时别动这两处。
