## related-work.md 怎么写

基于 `../research/pqc-ntt_ml-kem_compendium.md` 里那 22 篇论文，整理一张表：

| 列 | 说明 |
|---|---|
| 论文/作者/年份 | |
| 平台与器件 | 别人用的什么板子（注意区分器件规格与速度等级） |
| 折叠度 | 一次算几个蝶形 |
| 资源 | LUT / DSP / BRAM |
| 频率 | 注意标注测量条件（综合后估值 vs 布线后） |
| 与我们的差别 | **这一列才是这张表存在的理由** |

**已抽好的对比数据在** `../research/kyber_ref/papers/*.txt`
（`out_table.txt` / `pq_table.txt` / `pqshield.txt` / `mdpi_v*.txt`）——
那些 `.txt` 在仓库里，PDF 不在（版权，见 `../.gitignore`）。

⚠️ **从 PDF 抽出的表格要核对列有没有错位。** 已有先例：
`../rtl/vivado/folding_comparison.md` 记录过一次「论文的 LUT 数没对上，原因是 PDF 抽文本时列错位」，
那张表因此**不引用论文的 LUT 数，只引用我们自己重跑出来的频率**。
