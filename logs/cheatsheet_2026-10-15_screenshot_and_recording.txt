【准备】
1. 手机横屏架好，画面同时框住「笔记本屏幕 + 板子（电源灯亮着）」。
   不要用 Win+G —— 只录屏幕，拍不到板子。

2. 前面跑废的那一轮不要录进去 —— 重新开拍。

3. 开 Git Bash：Win 键 → 打字 git bash → 回车。
   提示符末尾是 $ 才对（末尾是 > 的是 cmd / PowerShell，开错了）。

4. 第一行手打，别粘：
     cd /e/FPGA

   ⚠️ 粘贴会踩坑：终端会在行首塞一个粘贴标记 ^[[200~，bash 把它和 cd 连成
   一个不存在的命令名，报
     bash: $'\E[200~cd': command not found
   cd 根本没执行，人还站在家目录 —— 后面五条会全部报
     can't open file "E:\FPGA\host\src\board_run.py"
   一条都跑不到板子，而报错长得像「脚本丢了」。

5. 核一下站对地方了（两条都要对，不对就别往下走）：
     pwd                        → /e/FPGA
     ls host/src/board_run.py   → host/src/board_run.py

6. 再敲一行：
     export PYTHONIOENCODING=utf-8
   敲完没有任何输出、直接跳回提示符 —— 这是对的，export 本来就不打印东西。

【开拍，一条一条敲，每条等它跑完再敲下一条】

7. powershell -NoProfile -Command "[System.IO.Ports.SerialPort]::GetPortNames()"

8. python host/src/board_run.py "#PING"

9. python host/src/board_run.py "#NTT 1"       --check --build 1

10. python host/src/board_run.py "#INTT 1"      --check --build 1

11. python host/src/board_run.py "#PMUL NTT 1"  --check --build 1

12. python host/src/board_run.py "#PMUL FULL 1" --check --build 1

【每条要按这个顺序出现在屏幕上】
  - 插座：真串口（115200-8N1），口号以第 7 步为准，不写死
  - 每条发出去的帧
  - 256 行收全
  - 0 / 256 不同
  - 耗时 0.18～0.27 秒
  - （全程）板子本身，电源灯亮着

【注意】
  - 不要录 #PMUL TIME 1。
  - 「开机行：没收到 #RDY」是正常的，脚本自己就带着这句解释，别停下来。
  - 哪条又冒出 ^[[200~，按 Ctrl+C 清掉重敲。

【存】
13. 停录，存：
      assets/2026-10-15_A_board_uart_five_transactions.mp4
