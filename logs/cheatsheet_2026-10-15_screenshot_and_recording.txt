§一  关键路径截图（存 2 张 png）
==================================================

【板级】
1. 开 cmd（不是 Git Bash）：
     cd /d C:\vivado_work
     E:\xilinx\Vivado\2020.2\bin\vivado.bat

2. 底部 Tcl Console 里敲这 3 行：
     open_checkpoint C:/vivado_work/dcp/ntt_board_pe1.dcp
     set p [get_timing_paths -from [get_pins u_line/line_len_reg[0]/C] -to [get_pins u_fsm/r_echo_reg[361]/CE] -max_paths 1]
     show_schematic [get_cells -of_objects [get_pins -of_objects $p]]

3. 截图前自查（Tcl Console 敲）：
     llength [get_cells -of_objects [get_pins -of_objects $p]]
   要回 13。回 0 就是没找到路径 —— 别截。

4. 截 Schematic 窗口（别缩放），存：
     assets\2026-10-15_A_critical_path_board_pe1.png

【核】
5. Tcl Console 里敲这 5 行（每条 pin 名各自成行，别并成一行）：
     open_checkpoint C:/vivado_work/dcp/pe1_nc.dcp
     set a {u_core/BTF_GEN_BLOCK[0].btfu/mm0/im0/P0/CLK}
     set b {u_core/BTF_GEN_BLOCK[0].btfu/w5r0_reg[3]/D}
     set p [get_timing_paths -from [get_pins $a] -to [get_pins $b] -max_paths 1]
     show_schematic [get_cells -of_objects [get_pins -of_objects $p]]

6. 自查：llength [get_cells -of_objects [get_pins -of_objects $p]]
   要回 11。

7. 截 Schematic 窗口，存：
     assets\2026-10-15_A_critical_path_core_pe1.png

【注意】
  - 核那两个 pin 名外层的 { } 不能去掉。
  - 核的 slack 显示 -0.936 / VIOLATED 是对的，别改、别当故障。
  - 截出来的必须是一条由方块和连线组成的路径图。若是芯片版图（大片深蓝格子），
    说明上一步没找到路径，回第 3 / 6 步自查。

§二  上板串口录屏（存 1 个 mp4）
==================================================

【准备】
1. 手机横屏架好，画面同时框住「笔记本屏幕 + 板子（电源灯亮着）」。
   不要用 Win+G —— 只录屏幕，拍不到板子。

2. 单独开一个 Git Bash 窗口，敲：
     cd "C:/Users/l'x/Desktop/FPGA"
     export PYTHONIOENCODING=utf-8

【开拍，一条一条敲，每条等它跑完再敲下一条】
3. powershell -NoProfile -Command "[System.IO.Ports.SerialPort]::GetPortNames()"

4. python host/src/board_run.py "#PING"

5. python host/src/board_run.py "#NTT 1"       --check --build 1

6. python host/src/board_run.py "#INTT 1"      --check --build 1

7. python host/src/board_run.py "#PMUL NTT 1"  --check --build 1

8. python host/src/board_run.py "#PMUL FULL 1" --check --build 1

【画面里要看到】
  - 串口号 + 115200-8N1
  - 每条发出去的帧
  - 256 行收全
  - 0 / 256 不同
  - 耗时 0.18～0.27 秒
  - 板子本身

【注意】
  - 不要录 #PMUL TIME 1。
  - 「开机行：没收到 #RDY」是正常的，别停下来。

【存】
9. 停录，存：
     assets\2026-10-15_A_board_uart_five_transactions.mp4
