题目：真板子第一次跑 —— `#NTT 1` 过了，`#PMUL NTT 1` 被上位机自己判成错位（`host.py` 一处）
--------------------------------------------------------------------------------

一、结论先说

  真板子（COM10，115200-8N1，今天重出的 pe1）第一次跑：

    `#NTT 1`        => **256/256 全中**
    `#PMUL NTT 1`   => **STOP**

  第二条**不是板子算错**，是上位机把板子一条**合规的**回帧判成了错位。
  **板子侧不用改。**

  ⚠️ 而这条 bug **不需要板子就能复现** —— 见第五节。

二、症状（真板子原样）

    #PMUL NTT 1：STOP，重试 1 次，周期「等 #BEGIN（T_BEGIN=5 s）」：
      收到 BEGIN 说明数据行 256，但命令带了 512 数据 → 对不上（§5.5:527）

三、为什么是「上位机判错」

  三处协议原文一致 —— **count 是「板子要发出去」的行数，不是「电脑要发进来」的行数**：

    · §5.1 关键规则三：「`#BEGIN <原命令> <count>` 里的 count 必须和后面
      **实际行数**相等」
    · §5.2 应答表：「`#BEGIN <原命令> <count>` ｜ count = **即将发出的数据行数**」
    · §5.1 完整事务示例（点乘）：电脑下行发 **512 行**（A 256 + B 256），
      板子回 `#BEGIN PMUL TIME 1 256*75` —— 注释写的就是「下面 256 行是结果」

  ⇒ PMUL 的 `#BEGIN` count = **256**（结果行数），而电脑发进去的是 512。
  两个数**本来就该不等**。

  板子侧的实装与注释（`rtl/board/proto_fsm.v:74`）：
    「#BEGIN <原命令> <count>   count = 即将发出的数据行数（计算类是 256）」
  —— 与协议一致，**A 不动**。

四、bug 的确切位置

  `host/src/host.py:443`

      if int(tail) != txn.count:
          return ("DESYNC", "%s 说的行数是 %s，本事务该是 %d —— 对不上（§5.5:527）"
                            % (want, tail, txn.count))

  `txn.count` 在同一个文件里**兼了三职**：

    `:303`  txn.stage = "发 %d 行数据" % txn.count        ← 发几行
    `:316`  for i in range(txn.count):                   ← 收几行
    `:443`  核对 `#BEGIN` / `#DONE` 的 count             ← 这条用的是「结果行数」

  三职只有在「进 = 出」时才同值：

    `#NTT`    256 进 256 出  ⇒ 三职同值 ⇒ **蒙对了**
    `#PMUL`   512 进 256 出  ⇒ `:443` 拿 256 比 512 ⇒ **假错位**

  ⚠️ **2026-10-08 订正 —— 本节所有 `host.py` 行号已因 B 的修复而位移。**
     上面那三处（`:303` / `:316` / `:443`）指的是**修前**那份 509 行的版本，
     写信当天是对的，**现在照着读会指到别处**。B 已于 2026-10-07 修完并推送
     （`671a91b`），`host.py` 现 **554 行**，等价逻辑落在这三处：

        `:349-350`   `for i in range(txn.recv)`                          ← 原来的 `:316`
        `:482`       `txn.recv = n`（`#BEGIN` 记下板子报的行数）
        `:488`       `if n != txn.recv:`（`#DONE` 与 `#BEGIN` 自洽核对） ← 原来的 `:443`

     `txn.count` 那个「一数三职」也已拆成 `sent` / `recv` 两个量 ——
     **本节描述的 bug 本身已经修掉了**，留在这里是病理记录，**不是待办**。

  ⚠️ 顺带 **`:316` 同源**：PMUL 时 `txn.count = 512`，即使 `:443` 放过，
     收结果也会**多读 256 行**（板子只回 256 行）。修的时候
     「**发送行数**」与「**结果行数**」得是两个量，不能共用一个。
