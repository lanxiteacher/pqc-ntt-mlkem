## ⚠️ AI 主动多说的一句是错的：断言「署名串了」

**AI 多说的那句**（原话）

> **署名串了**：`3f7e7d6`（内容以 C 名义建的 `skill/`+`report/` 骨架）作者是
> `lanxiteacher`（A 的身份），不是 `于宸`。只有 `efcf33c` 署到了你名下。……
> 按只增不改的惯例在 `_变更.md` 记一笔更正即可。

**哪里不对**

这条判断是**错的**。`3f7e7d6` 改的 9 个文件全是 A 自己的文档
（`CLAUDE.md`、四个 `README.md`、C 引导指南、`team/` 两份、`logs/`），
**没有一个落在 C 的主责目录**。提交信息里的「C 加入：」是**主题标签**
（= 为 C 加入做准备），不是署名。

**怎么发现不对的**

A 回了信，让我**先跑两条命令再判断**：

```
git show --stat 3f7e7d6
git show --stat efcf33c
```

跑了 —— `3f7e7d6` 的文件确实全在 A 的文档上；`efcf33c` 才是那 8 个 `.gitkeep`。
**我错在只看提交信息的主题词就推断署名归属**，没跑 `--stat`。

**A 补的一条惯例**（原话）

> 请在 `_变更.md` 里**不要**记这条更正。往只增文档里写一条不存在的更正，是给后来的人加噪声。

**改完对不对**

撤回该判断，未写入 `_变更.md`。以后断言「谁提交的 / 某文件属于谁」之前先 `git show --stat`。
