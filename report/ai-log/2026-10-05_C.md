## 主线二：修 A 点名留给 C 的那处缺陷

**哪里不对**（A 在信里给的现象）

`skill/scripts/check_reproducible.sh` 在 A 本机跑不通：

```
fatal: repository '/c/Users/l'x/Desktop/FPGA' does not exist
```

**根因**（A 已试出来，不是猜的）：仓库路径里的**撇号**让 MSYS 的路径转换失效 ——
`git clone "/c/Users/l'x/…"` 失败，而同一个仓库的 `"C:/Users/l'x/…"` 能成功。

**AI 答了什么**

根的病灶是脚本把 `pwd` 给的 MSYS 形态路径（`/c/…`）**原样喂给 `git clone`**。
加一个 `to_native_path()`：有 `cygpath` 就用 `cygpath -m`，否则手写
`sed -E 's|^/([A-Za-z])/|\1:/|'`（只匹配「单字母盘符」，Linux 的 `/home/…` 不受影响）。
**只对本地 clone 那一支做转换**，`--from-remote` 走的是 URL，不动它（避免把 `https://…` 喂给 `cygpath`）。

**改完对不对**

- 单测转换函数：`/d/FPGA` → `D:/FPGA`；含撇号的 `/c/Users/l'x/…` → `C:/Users/l'x/…`；
  Linux 形态 `/home/user/foo` 在无 `cygpath` 的回退分支下**不被改**。
- **整脚本跑通**：`sh skill/scripts/check_reproducible.sh` → clone 成功（认到 `bdc4c78`）、
  产物文件检查通过、四条入口脚本因**缺工具**正确走「跳过」、退出码 **2**。
  ⚠️ 本机路径 `D:\FPGA` **没有撇号**，所以**复现不了 A 那个故障** ——
  我能验的是「转换函数把带撇号的路径转对了」+「脚本本身没被改坏」，这两条都过了。
