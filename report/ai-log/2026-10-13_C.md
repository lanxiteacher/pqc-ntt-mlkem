## 真发现（一处，属「旁白照印象写、没对页面实物」这一类）

### 段 3 旁白把对拍页说成了「左 RTL／右黄金」左右分栏 —— 页面上没有这个布局

`demo/video_script.md` 段 3 原文：

> 这一页**左边是 RTL 仿真真正落盘的输出，右边是黄金向量**。**4096 个系数，逐位比，全绿。**

回 `demo/compare.html` 核实物 —— **它是一整片格子**（`<div class="grid" id="grid">`，256 格），
**每一格显示的是 RTL 落盘的那个值**，格子的颜色才是「与黄金向量是否一致」
（绿 = 一致、红 = 不一致）。右栏是「点一个系数 / 各项运算判定 / 非退化统计 / 阴性对照 / 覆盖边界」
五个信息盒，**不是「黄金向量」那一列**。而 **4096/4096 出现在页头**（`${F.totalMatch} / ${F.total}`），
是一组一组的 256 凑起来的**汇总数**，不是网格本身摆着 4096 格。

- **根因**：旁白是**照印象写的** —— 「对拍」这个词在脑子里默认是「两列并排比」，
  而页面实际做的是**单网格 + 按颜色判等**，汇总数在表头。写旁白时没对着页面实物核。
- **判据**：不是读旁白自己那句，而是**打开 `compare.html` 数它有几个 `<div>`、格子显示的是谁的值**。
- **这和 10-12 那条同源**：10-12 咬的是「描述**机器**的陈述会过期」，今天咬的是
  「描述**画面**的陈述没对实物」—— 两句都属「写着的东西和当下不符」，只是一个管环境、一个管界面。

## 追加：把段 0 / 段 8 的标题卡建成了页面（`demo/title.html`）

### 为什么建

收工时把「标题卡没现成素材」这条报给用户，问要不要备成页面 —— **用户答「可以」**，当天就做。
理由：段 0 / 段 8 是视频的头尾，**「录真东西，不摆拍」**这条口径连字卡也适用 ——
在演示页同款主题里录一块真页面，比剪片时临时拼一张字卡更一致、也留了痕。

### 怎么建的（复用，不另起一套）

- **复用 `ntt-view.js` 的 `css()`** —— 主题那组 CSS 变量（深色默认 / `?theme=light` 浅底）
  一个字没改就接到了卡面上，所以**卡与演示页是同一套色**，不会各写各的。
- 两版卡面：**片头**（项目名 + 三人 + 仓库地址 + 一句定位）、**结尾**（零基础 / AI-agent / 开源 + 仓库地址）。
- 交互：空格 / ←→ 切换两卡；**`?ui=0` 隐藏按钮**（录屏用，画面干净）；`?card=outro` 直接开结尾卡。
- 1920×1080 满屏居中。

### AI 在这里帮了什么、我又核了什么

- 一次性生成页面骨架很快；**但「卡面写什么」不能信 AI 的记忆** —— 项目名、三人姓名、
  仓库地址都回仓库核了原文（`design/00_front_matter.md` §一 / §二 的名字写法、
  `logs/project_state.md` §一 的仓库串），**没凭印象填**。这三样任一写错，录进视频就是硬伤。
- **渲染核验**：本机没有 GUI，仍走**无头 Edge**（与 `gen_shots.mjs` 同一条路）——
  对片头卡、结尾卡、浅色主题各截一张 1920×1080，**逐张看过**（对齐、换行、强调色都对）。
  核完把三张临时图删掉，**不进仓库**（它们是过程产物，视频要录的是活页面）。
