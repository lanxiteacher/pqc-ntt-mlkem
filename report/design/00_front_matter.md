## 二、摘要

> 后量子密码标准 ML-KEM（FIPS 203）里，最耗时的运算之一是数论变换（NTT）。
> 本作品为 ML-KEM 的 **NTT / INTT / 点乘**在 FPGA 上实现了一个**折叠度可配置**的硬件加速核：
> 同一套 Verilog RTL，只改一个 `PE_NUMBER` 参数，即可在「每拍 1 / 4 / 16 个蝶形」三档之间切换。
>
> 设计的取舍集中在一点：上游写法把数据口宽度绑成 `12 × 蝶形数`，做到 16 蝶形需要 **397 个引脚**，
> 而本器件只有 **125 个**，布局直接失败。对策是**核内保持宽接口、把序列化移到核外、对外固定 12 位** ——
> 三档对外引脚数恒为 **37**，三档全部走完综合、布局、布线并**在真板子上跑通**。
>
> 功能正确性由 FIPS 203 **兼容**考题（1000 条全过）与一份 C 参考实现逐点对拍保证：
> 4096 个系数**逐比特一致**，并附**阴性对照**（故意改坏即塌成随机）证明判据有效。
> 资源占用、时序、关键路径与板级实测的原始报告全部入库，可逐数溯源。
>
> 作品全程采用大模型辅助的工程方法，从算法调研、RTL 改造到验证对拍与文档，
> **完整记录了人机协作的过程与自我纠错轨迹**（见附录）。

（约 330 字。各数字出处：折叠度三档与 397/125 引脚 → §2.1、§2.2；
1000 条 KAT 与 4096 逐比特 → §4.4；三档真板子 → §3.13 / §4.8；
阴性对照 → §4.7。**成文时回源头核一遍**。）

**算法与标准**

| 缩写 | 英文全称 | 中文 | 说明 |
|---|---|---|---|
| **PQC** | Post-Quantum Cryptography | 后量子密码 | 抗量子计算攻击的密码体系；本作品所属领域（**报告正文统一写中文「后量子密码」**） |
| **ML-KEM** | Module-Lattice-Based Key-Encapsulation Mechanism | 模块格基密钥封装机制 | NIST 后量子标准 **FIPS 203** 的算法，本作品加速的对象 |
| **KEM** | Key-Encapsulation Mechanism | 密钥封装机制 | 通信双方协商共享密钥的机制 |
| **FIPS 203** | Federal Information Processing Standard 203 | （美）联邦信息处理标准 203 | ML-KEM 的正式标准 |
| **NTT** | Number Theoretic Transform | 数论变换 | 多项式乘法里的核心变换；ML-KEM 最耗时的一步，**本作品主攻对象** |
| **INTT** | Inverse Number Theoretic Transform | 逆数论变换 | NTT 的反向变换 |
| **FNTT** | Forward Number Theoretic Transform | 正向数论变换 | 本项目 RTL 里对「一次正向变换」的称法（与 INTT 成对） |
| **PWM2** | Point-Wise Multiplication（2 bank） | 点乘 | 本项目 RTL 模块名；NTT 域下两组系数逐点相乘（即 `basemul`），A/B 两个 bank 各装一组 |
| **K-PKE** | (Kyber) Public-Key Encryption | （Kyber）公钥加密 | ML-KEM 内层的公钥加密部件，**本作品不实现** |
| **CBD** | Centered Binomial Distribution | 中心二项分布 | 噪声采样分布，**本作品不实现** |

| 缩写 | 英文全称 | 中文 | 说明 |
|---|---|---|---|
| **RTL** | Register-Transfer Level | 寄存器传输级 | 用 Verilog 描述「每个时钟沿寄存器怎么变」的设计层次；本项目交付的设计 |
| **FPGA** | Field-Programmable Gate Array | 现场可编程门阵列 | 可反复改电路的芯片 |
| **PL** | Programmable Logic | 可编程逻辑 | Zynq 里的 FPGA 部分；**本作品全部实现都在 PL 内** |
| **PS** | Processing System | 处理系统 | Zynq 内嵌的 ARM 核；**本作品不使用**（纯 PL） |
| **HLS** | High-Level Synthesis | 高层次综合 | 用 C/C++ 生成 RTL 的流程；**本作品不使用**（手写 Verilog） |

**资源与时序**

| 缩写 | 英文全称 | 中文 | 说明 |
|---|---|---|---|
| **LUT** | Look-Up Table | 查找表 | FPGA 的通用逻辑资源 |
| **FF** | Flip-Flop | 触发器 | FPGA 的寄存器资源 |
| **DSP** | Digital Signal Processing (block) | 数字信号处理块 | 专用硬件乘法器；本作品每档恰好用「蝶形数」个 |
