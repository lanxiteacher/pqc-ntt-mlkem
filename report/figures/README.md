## 三、格式约定

- **矢量优先**：能生成 SVG 就用 SVG（Word / LaTeX 都能插，放大不糊）
- 位图截图用 **PNG**（不用 JPG —— 波形和界面上有细线，JPG 会糊）
- 文件名**英文小写 + 下划线**（本目录沿用 `skill/` 的口径，两条规则下都合规）
- 每张图在 `design/` 正文里要有一句「这张图说明什么」，不要只贴图不解释
