1. 为什么只有 7 层？—— 从 q-1 的 2-adic 赋值推
======================================================================
  q              = 3329
  q - 1          = 3328
  q - 1 分解      = 2^8 × 13
  2 的幂次部分    = 2^8 = 256
  负循环卷积长度 n = 256，需要 n 次单位根 -> 2^8 >= 256 ? True
  完整分裂需要 2n = 512 次单位根 -> 2^8 >= 512 ? False

  结论: q-1 只含 2^8，够做 256 点变换，不够做 512 次单位根
        -> X^256+1 无法完全分解成 256 个一次因子
        -> 只能分解成 128 个二次因子 X^2 - zeta^(2i+1)
        -> NTT 只做 log2(128) = 7 层  <-- 这就是「不完整 NTT」

2. 逐个验证上面每条断言
======================================================================
  17 是 mod q 的本原 256 次单位根 ? 17^256=1, 17^128=3328  -> 是
  方程 x^256 = -1 (mod q) 有解 ? False   (gcd(256,q-1)=256, 判据 (-1)^((q-1)/g)=(-1)^13=-1)
    -> 不存在本原 512 次单位根，所以二次因子不可再分
  zeta^(2i+1) 共 128 个互不相同的值（应 128）
  这些值的 Legendre 符号集合 = {-1}  -> 全为 -1 表示 X^2 - zeta^(2i+1) 在 Z_q 上不可约
  -> 二次因子确实不可再分，128 个因子两两互素
  数值验证: prod_i (x^2 - zeta^(2i+1)) == x^256 + 1 (mod q)  ? True

======================================================================
3. 层数与规模
======================================================================
  层数        = 7   (2^7 = 128)
  每层蝶形数   = 128 (共 128×7 = 896 个蝶形)
  每个蝶形     = 1 次模乘 + 1 次模加 + 1 次模减
  正向模乘总数 = 896
  逆向模乘总数 = 896 + 256(末尾统一缩放 f=1441) = 1152
  basemul 逐点乘 = 64 组 × 2 = 128 次 basemul，每次 5 次模乘 = 640 次模乘
